# Tarea Clase 12 Dashboard Proyecto Final 
## Grupo 11

## Descripción
Sistema logístico desarrollado para gestionar envíos y analizar información mediante Inteligencia de Negocios.

El proyecto integra una base de datos relacional, una interfaz gráfica y un dashboard interactivo en Power BI para apoyar la toma de decisiones.

## Funcionalidades
- Registro de envíos
- Consulta de envíos
- Actualización y eliminación de registros (CRUD)
- Manejo de excepciones
- Interfaz gráfica (GUI)
- Dashboard interactivo con filtros
- Análisis de datos mediante KPIs y DAX
